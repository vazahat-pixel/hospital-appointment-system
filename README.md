# Hospital Appointment System (MERN) — Single Project

This project contains **backend** (Express + MongoDB) and **frontend** (React + Vite + Tailwind) in one folder.

## Quick Start

### 1) Backend
```bash
cd backend
npm install
npm run dev
```
> API: http://localhost:5000

### 2) Frontend
Open a new terminal:
```bash
cd frontend
npm install
npm run dev
```
> Web App: http://localhost:5173

### Default Features
- Register/Login (Doctor or Patient)
- List Doctors / Patients
- Book Appointment (patients)
- View My Appointments (doctor/patient)
- Cancel Appointment (owner only)
- Responsive UI with Tailwind
